### 3. ADVANCED QR CODE CUSTOMIZATION & GENERATION FEATURES (COMPREHENSIVE)
1. **Universal Content Support:** Generate QR codes for *everything*—Website URLs, Plain Text, Wi-Fi Networks (SSID, password, encryption), vCard digital business cards, WhatsApp direct chat messages, PDF files, and phone numbers.
2. **Deep Visual Customization & Styling (`qr-code-styling`):**
   - **Dot & Shape Styles:** Full control over dot matrix patterns (Square, Rounded, Dots, Classy, Fluid).
   - **Colors & Gradients:** Advanced foreground and background color pickers with visual palette pickers and custom hex code input.
   - **Border & Center Eye Styles:** Custom outer frame borders and inner center eye shapes (circles, squares, custom geometry).
   - **Call-to-Action Frames:** Selectable badge frames and templates (e.g., "Scan Me" speech bubbles, icon frames).
3. **Custom Logo & Branding Integration:**
   - **Preset Brand Icons:** Quick-select overlays for popular icons (Instagram, WhatsApp, YouTube, Globe, Shopping Bag, etc.).
   - **Custom Logo Upload:** Drag-and-drop or file upload zone (`.png`, `.jpg`, `.svg`) allowing users to place their brand logo directly in the center of the QR code with automatic scaling and background padding.
4. **Error Correction Levels:** Toggle between Error Correction Levels (L, M, Q, H) so codes remain scannable even when customized or partially covered by logos.
5. **Industrial Barcode Suite (`jsbarcode`):** Code 128, EAN-13, UPC-A, Code 39 with a smart check-digit validation engine.
6. **Bulk ZIP & Printable Label Grids:** Multi-line textarea batch generation packaged into `.zip` files, plus an A4/Avery sticker sheet grid printer (`@media print`).
7. **Camera OCR Scanner (`tesseract.js`):** Scan physical text using the device camera (`navigator.mediaDevices`), extract text via WebAssembly OCR, and auto-populate the generator.

### 4. MOBILE-FIRST RESPONSIVE DESIGN & ERGONOMICS
- **Desktop (min-width: 1024px):** Two-column master grid (`max-w-6xl mx-auto grid-cols-12 gap-6 items-start`). Left controls (`col-span-7`), right sticky preview (`col-span-5`).
- **Mobile (max-width: 1023px):** Single-column stacked layout. 
- **Fixed Thumb-Zone Bottom Action Bar:** On mobile viewports, lock primary action buttons (`[ Download PNG ]`, `[ Download SVG ]`) to the bottom screen edge (`fixed bottom-0 left-0 right-0 z-50 bg-white/95 backdrop-blur p-3 border-t flex gap-2 shadow-xl`) so users never have to scroll down to download.
